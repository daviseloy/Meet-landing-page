# Meet Landing Page

Projeto desenvolvido como parte dos desafios da plataforma **Frontend Mentor**.

O objetivo foi reproduzir uma landing page para o Meet, uma plataforma de comunicação e videoconferências, utilizando HTML e CSS, com foco em design responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Fonts (Red Hat Display)

## Funcionalidades e características

- Layout responsivo para desktop, tablet e dispositivos móveis.
- Organização de elementos utilizando Flexbox.
- Imagens posicionadas e adaptadas para diferentes tamanhos de tela.
- Uso de variáveis CSS para cores e espaçamentos.
- Efeitos de interação nos botões (`:hover`).

## Responsividade

O projeto foi desenvolvido considerando três principais resoluções:

- **Desktop:** layout completo com imagens laterais no hero.
- **Tablet:** reorganização dos elementos e adaptação das imagens.
- **Mobile:** conteúdo reorganizado para telas menores, com galeria de imagens em grade 2×2.

## Aprendizados

Durante o desenvolvimento, pratiquei:

- Estruturação de páginas com HTML semântico.
- Posicionamento e dimensionamento de elementos com CSS.
- Uso de Flexbox para organizar layouts.
- Aplicação de Media Queries.
- Resolução de problemas de overflow e alinhamento.
- Adaptação de imagens para diferentes resoluções.
